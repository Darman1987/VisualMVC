# C# Visual MVC Repository

This repository demonstrates the **MVC (Model-View-Controller)** architectural pattern implemented in **C#**, showcasing how to organize code for maintainability and separation of concerns. It features two key branches to illustrate different levels of MVC architecture.

---

## 📁 Branches Overview

| Branch Name             | Description                                                                 |
|-------------------------|-----------------------------------------------------------------------------|
| `Controller-View`       | Basic implementation of the MVC pattern with only **Controllers** and **Views**. Ideal for beginners learning how logic and UI interact in a structured way. |
| `Controller-View-Model` | Full MVC implementation including **Models** for managing application data and business logic, i
